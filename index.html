Projects I host on GitHub Pages. Each one has its source on GitHub.

Transit & cities

  • NYC subway ridership mapsource

    Riders aboard every NYC subway train, inferred from turnstile counts and the timetable, on an animated map.

  • Extrapolation sciencesource

    Where is the bus right now? Hypotheses for extrapolating vehicle positions past the last GPS fix, tested against real AVL data.

  • routelabsource

    Reference implementations of routing algorithms, with a Python veneer over Rust kernels.

  • The City and the Bikesource

    An app for finding, photographing and cataloging the graffiti tags on rental bikes' rear fenders.

Geometry & CAD

  • Solvent sketchersource

    A geometric constraint solver and the declarative language its drawings are written in, running in the browser.

  • brep-benchsource

    Rosetta Code for B-rep CAD kernels: the same solids built in each kernel, graded the same way, and shown side by side.
